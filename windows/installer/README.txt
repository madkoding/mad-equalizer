MAD EQUALIZER 2.0 FOR WINDOWS
16-band stereo graphic equalizer for all of your PC's audio
=====================================================================

REQUIREMENTS
  • Windows 10 or 11, 64-bit
  • Equalizer APO (free) - included in the installer


INSTALLATION
  1. Run MAD-Equalizer-2.0-Setup.exe and accept the administrator prompt.
  2. If Equalizer APO is not installed yet, its installer opens
     automatically. When it shows the "Configurator", CHECK THE DEVICES
     YOU LISTEN ON (headphones, speakers, HDMI...) and click OK.
  3. Restart Windows when asked. Equalizer APO only starts working after
     a restart.
  4. Open MAD Equalizer from the Start menu or the desktop shortcut.


WINDOWS WON'T LET ME RUN IT ("WINDOWS PROTECTED YOUR PC")
  The installer isn't signed with a paid certificate, so SmartScreen
  warns you after downloading it. Click "More info" and then
  "Run anyway".

  If Windows still blocks it, remove the "downloaded from the internet"
  mark. Right-click the file > Properties > check "Unblock" > OK.
  Or open PowerShell in the folder where the file is and run:

       Unblock-File .\MAD-Equalizer-2.0-Setup.exe


THE EQ HAS NO EFFECT
  • Make sure Equalizer APO is enabled for the device you're listening on:
    in MAD Equalizer click "OUTPUT" on the display (it opens the Equalizer
    APO Device Selector), check your device, and restart Windows.
  • Windows 11: Settings > System > Sound > (your device) >
    "Audio enhancements" must be set to "Device default effects", not Off.
  • Bluetooth headphones and USB devices count as separate devices: each
    one has to be checked in the Device Selector.
  • If it still doesn't work, in the Device Selector open
    "Troubleshooting options" and enable "Install as SFX/MFX".

  The display shows "APO" lit when MAD can write Equalizer APO's
  configuration. "EQUALIZER APO NO INSTALADO" means it isn't installed.


QUICK GUIDE
  • Volume: use your Windows volume keys as usual.
  • Faders: drag the cap or click the track. Double-click = 0 dB.
  • Knobs: drag up or down. Double-click = default value.
  • STORE + M1–M4 saves a curve; M1–M4 recalls it. A/B compares two.
  • ANTI CLIP lowers the gain just enough for the curve not to clip.
  • LUFS I: click the number to reset the measurement.
  • POWER off or BYPASS: audio passes through unchanged.
  • The meters read a copy of what's playing; nothing is recorded or saved.


UNINSTALL
  Settings > Apps > Installed apps > MAD Equalizer > Uninstall.
  Equalizer APO is a separate program: uninstall it the same way if you
  no longer want it.
